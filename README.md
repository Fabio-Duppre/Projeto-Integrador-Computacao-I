# Projeto-Integrador-Computacao-I

Repositório do Projeto Integrador I desenvolvido para o curso de **Ciência de Dados da UNIVESP**, durante o 4º período.

## Para executar o projeto

### 1. Instalar as dependências

Após clonar o repositório, instale as dependências utilizando:

```bash
python -m pip install -r requirements.txt
```

### 2. Executar o projeto

Após a instalação das dependências, execute a aplicação com:

```bash
python app.py
```

## Sobre o projeto

O projeto apresenta um formulário composto por perguntas e respostas de múltipla escolha, desenvolvido para a aplicação da **escala DASS-21**.

Além do formulário, o sistema possui uma página destinada à **visualização dos dados**, permitindo apresentar de forma gráfica as informações obtidas durante a utilização da aplicação.

## Tecnologias utilizadas

O projeto foi desenvolvido utilizando:

* **Python**
* **Flask**
* **HTML5**
* **JavaScript**
* **SQLite**
